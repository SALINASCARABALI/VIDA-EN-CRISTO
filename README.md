Tu mano en el arado

Página web personal sobre mi vida en Cristo, hecha con HTML, CSS y JavaScript mientras aprendo a programar.

"Sin Jehová no soy nada"

Qué contiene
Mi vida en Cristo: mi testimonio y lo que Dios ha hecho en mi vida.
Carrusel de frases que cambian solas.
¿Por qué seguí a Cristo?: mi historia.
Mis metas espirituales: una lista de propósitos.
Versículo aleatorio y saludo según la hora.
Botón para volver al inicio y cajas que aparecen suavemente al hacer scroll.
Tecnologías
HTML5
CSS3 (degradados, flexbox, animaciones)
JavaScript
